# 🎬 Movie Recommendation System

An ML-powered web app that recommends similar movies instantly!

## 📌 Features
- 🎯 Content-based filtering using Machine Learning
- 🔍 Search from 4800+ movies
- 🎬 Get 5 similar movies instantly
- ⚡ Fast recommendations using Cosine Similarity

## 🛠️ Tools Used
- Python 3.12
- Pandas
- Scikit-learn
- Streamlit

## 🚀 How to Run
1. Clone the repository
2. Install dependencies: `pip install pandas scikit-learn streamlit`
3. Add dataset CSV files in the same folder
4. Run: `streamlit run app.py`
